NiAlphaProperty
 
Дефолтный 237 флаг.
Включено только смешивание альфы.
Хорошо видно наложение полигонов на альфа канал текстуры.
 
4845 Threshold 0
Этот флаг эффективно убирает перекрытие полигонов, за счет включения функции тестирования.
4845 Threshold  50
влияние этого значение на отсечение полностью прозрачных пикселей.

4844ый флаг с повышенным значением тресхолда.
 
По отношению к 4845 флагу, для 4844го значение тресхолда должно быть всегда выше!
 
4844 - если попытаться сделать с помощью оного витраж...

Тресхолд с высоким значением, проделал дырочку в центре, иначе объект выглядит совершенно не прозрачным.
А если поднять его значение до 200-255, объект и вовсе исчезнет!
